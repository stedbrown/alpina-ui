## Candidate 2 regression coverage

- Print short invoices with their payment slips on one A4 sheet and paginate a ledger with repeated column headings.
- Exercise the residence workflow through review and server errors. Exercise booking calendars in 180 CSS pixels and viewport notifications on a 360 px phone.
- Build a Next.js dynamic invoice page with Cache Components and verify its output from the installed package.

## Before publishing 1.0

- [x] Audit the archived public entry points, review deprecations and execute the migration examples.
- [x] Exercise the packed candidate with both supported React/React DOM endpoints in Next.js, Vite with React Router, and React Hook Form.
- [x] Run the candidate build, types, API report, Node, browser, visual, bundle, integration and performance checks.
- [x] Make installation and rollback reproducible with versioned archives and a candidate digest.
- [ ] Record the maintainer’s decision for each Beta contract after review with its consumers.
- [ ] Record a manual keyboard and screen-reader pass for files, the public-service workflow, forms, overlays and printed payment alternatives. Include Windows high contrast and at least one touch device.
- [ ] Obtain native-speaker review of field errors, assistive announcements and administrative terms in the four national languages.
- [ ] Obtain maintainer approval for the first stable npm publication. [Maintainer workflow](npm-release.md)
