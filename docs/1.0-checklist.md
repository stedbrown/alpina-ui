## Round 11 regression coverage

- Submit both migration specimens, copy their runnable sources and check the component equivalents. Increase the reservation form to 400% and reach each field by keyboard.
- Traverse the shared navigation on paper, ink and red surfaces, including a phone and a 200% text setting. Check the active route, theme persistence, version and GitHub actions.
- Exercise phrase searches in all four national languages, the visible Switch label, the mobile payment disclosure, and whole-word display type in a narrow grid column.
- Install the project skill from GitHub. Compile and render all five packaged examples and the four independently authored applications. [Customer briefs, results and remaining limitations](skill-trials/README.md)

## Candidate 5 domain verification

Run `node scripts/verify-domain.mjs` against the production release. It checks the sitemap, permanent redirects and installation from both website addresses. Run `npm run test:performance -- --deployed` to measure the homepage, Button and Login over HTTPS.

The maintainer manages domain registration, email addresses and social profiles. The site continues to deploy from the existing GitHub repository to the existing Vercel project.

## Candidate 4 regression coverage

- Render every catalog example and copyable block in a consumer with only the distributed styles and fonts. Inspect the standalone Italian postal-code hint and error.
- Read an invoice line and a payment slip at 360 px. Enlarge the QR slip with the keyboard, then print to A4 and verify the physical payment section.
- Search the MCP registry with multilingual accounting, dialog, chart and menu terms and misspelled queries. Read the package version from an installed consumer.
- Exercise the poster at 320, 768, 1440 and 2560 px in both themes, including keyboard input, specimen zoom, the local contrast palette and reduced motion.
- Verify both historical 0.11 URLs in production, including the fragment for the 0.11 changelog entry.

## Candidate 3 regression coverage

- Check the Lugano postcode error inside a narrow group and linked document numbers in custom table cells. Measure the space between adjacent two-digit days at 180 CSS pixels and verify the full progress list in the municipal form at 1280 pixels.
- Print alternate tab panels, generate QRR and RF references from grouped identifiers, change inherited locales and submit the accepted portion of a mixed file selection.
- Crawl the public guide links, check the permanent redirects and translated alternates, run the multilingual MCP queries, and typecheck the skill’s four examples from the packed dependency.
- After deployment, run `node tests/guide-links.browser.mjs --deployed` to check that every retired URL returns its 301 in a single response, including `/releases/0.11/`.
- Review the poster, live specimens and flat-topped peak in both appearances and exercise keyboard, reduced-motion and Lighthouse checks.

## Candidate 2 regression coverage

- Print short invoices with their payment slips on one A4 sheet and paginate a ledger with repeated column headings.
- Exercise the residence workflow through review and server errors. Exercise booking calendars in 180 CSS pixels and viewport notifications on a 360 px phone.
- Build a Next.js dynamic invoice page with Cache Components and verify its output from the installed package.
