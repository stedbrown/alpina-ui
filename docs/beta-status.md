# Beta decisions for 1.0

The maintainer is reviewing which Beta components can join the 1.x stability guarantee. The public registry continues to mark these entries Beta until a decision is recorded. Check the [component status table](https://alpinaui.com/status/) before adopting a Beta API.

The [maintainer review](https://github.com/stedbrown/alpina-ui/blob/main/docs/beta-review.md) lists every proposal, its rationale and the outstanding device, assistive technology or physical printing checks. See [API stability](https://alpinaui.com/docs/guides/api-stability/) for the compatibility guarantees that apply today.
