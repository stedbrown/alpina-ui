## Version 0.9.0

Install the versioned archive in an existing React 18.2 or 19 project. Applications that import the package can continue using the same component names. For locally copied components, run `npx --no-install alpina diff` after installing the new version to review changes. [Download the 0.9.0 package](https://alpinaui.com/alpina-ui-0.9.0.tgz) · [CLI guide](https://alpinaui.com/docs/guides/cli/)

```sh
npm install https://alpinaui.com/alpina-ui-0.9.0.tgz
```

- **Router links and refs.** `Button`, `Badge`, `TextLink` and individual menu or breadcrumb items accept `asChild`. Supply one element that forwards its props and ref to the underlying control. Leaf components forward refs and preserve caller classes alongside their library classes. [Migration guide](https://alpinaui.com/docs/guides/migration/)
- **Typography and themes.** Import `alpina-ui/fonts.css` to serve the Latin Inter WOFF2 files from your own application. Tables, CHF amounts and Swiss dates use tabular figures. The optional `alpina-ui/tailwind.css` bridge maps Tailwind v4 utilities to Alpina tokens. The theme builder previews light and dark combinations, reports text contrast and exports the CSS variables. [Design guide](https://alpinaui.com/docs/guides/design/) · [Theme builder](https://alpinaui.com/themes/)
- **Swiss forms and billing.** `IbanInput`, `AhvInput` and `PhoneInput` validate entries and format completed numbers on blur. `SwissQrBill` renders a SIX 2.4 payment section with a scannable QR Code. Use `printSwissQrBill` to print the selected slip and follow the print guide to check the result on paper. [Swiss forms](https://alpinaui.com/docs/guides/swiss/) · [Swiss QR-bill guide](https://alpinaui.com/docs/guides/qr-bill/)
- **Copyable pages.** Use `npx --no-install alpina add block/dashboard` to copy the dashboard into your app. The login, dashboard, account settings and CHF pricing pages use public Alpina components. Their source exposes the data and callbacks that connect them to your application. [Block gallery and installation commands](https://alpinaui.com/blocks/)

### Interaction changes

- Tab now enters a toggle group once. Use the arrows to move focus and Space to toggle a choice. Action menus accept a `shortcut` hint for an application-defined keyboard binding.
- The address form confirms a successful save in the active language. Error text appears before the invalid control. To customize the new confirmation, supply `labels.saved`.
- Pass `clearable` to a date picker or `clearLabel` to a combobox to offer a way to remove a selection. Their default selection behavior is preserved.
- Data tables expose sorting instructions through `sortHint`. Translate the hint for multilingual tables. Numeric cells align amounts without splitting ordinary franc values.

Projects that copied source can inspect their local changes with `npx --no-install alpina diff` before updating. [CLI guide](https://alpinaui.com/docs/guides/cli/)

## From 0.4 to 0.5

All imports and 77 registry identifiers from 0.4 remain available. Version 0.5 adds `Stack`, a single-axis layout component with modular spacing, alignment, and wrapping, bringing the registry to 78 entries. Version 0.5.1 introduced the English catalog and documentation.

## Action menus

Existing items with `value`, `label`, `disabled`, and `onSelect` continue to work. Add a divider before an item with `separatorBefore`, and use `tone="danger"` for a removal action. The menu's `align` and `size` props let it sit at the edge of a row. The portal example demonstrates editing and removing a record with explicit confirmation.

## Language selection

When you omit `locales`, `LocaleSelect` shows all four Swiss national languages. For a bilingual service, pass `locales={['it-CH', 'de-CH']}` and use the same two locales in application state.

## Updating copied source

Install the local package, then compare your files with `npx --no-install alpina diff dropdown-menu locale-select`. If you used a custom destination, pass the same `--dir` option. Add the new layout component with `npx --no-install alpina add stack`. Review local customizations in the diff before applying an update.
